# 수면주기 알람 (SleepCycleAlarm)

갤럭시 워치가 잠든 걸 감지하면 → 수면 모드로 폰 방해금지가 켜지고 → 그 순간을 잡아서
`잠든 시각 + 90분 × N`에 알람을 맞추는 개인용 안드로이드 앱.

## 동작
1. `SleepListenerService`(알림 리스너)가 방해금지 켜짐을 감지
2. 잠든 시각 = 감지 시각 − 감지 지연 보정(기본 10분)
3. 기상 시각 = 잠든 시각 + 90분 × 목표 주기(기본 5)
   - 마감 시각(기본 08:30)을 넘으면 주기를 하나씩 줄임(최소 3). 그래도 넘으면 마감 시각에 울림
4. 같은 밤에는 한 번만 설정함. 깼다가 다시 잠들어 신호가 또 와도 알람을 뒤로 밀지 않음
5. 알람은 덧셈 문제를 풀어야 꺼짐. 뒤로가기로는 못 끔
6. 끈 뒤 10분 뒤에 확인 알람이 한 번 더 울림 (다시 잠들었는지 확인)
7. 인정 시간대(기본 21시~6시) 밖에서 켜진 방해금지는 무시함

## 빌드
1. Android Studio로 이 폴더 열기 (Gradle sync가 끝날 때까지 기다리기)
2. 폰에서 개발자 옵션 → USB 디버깅 켜고 연결 → ▶ Run
   - 또는 Build → Build APK(s)로 APK를 만들어 폰에 설치

## 처음 설정 (앱 화면에서 위에서부터 차례로)
1. ① 알림 접근 허용 → "수면주기 알람" 켜기  ← 이게 없으면 감지가 안 됨
2. ② 알림 권한, ③ 전체화면 알림 허용
3. ④ 배터리 최적화 제외 (삼성은 앱을 자주 재움). 설정 → 배터리 → 백그라운드 사용 제한에서
   "절전 예외 앱"에도 넣어 두면 더 안전함
4. "1분 뒤 테스트 알람"으로 화면을 끈 상태에서 울리는지 확인

## 워치 쪽 확인할 것
- 워치 설정 → 모드 → 수면 모드에서 **잠들면 자동으로 켜기**가 켜져 있는지
- 갤럭시 웨어러블 앱에서 **폰과 모드 동기화**가 켜져 있는지
- 하룻밤 자 보고 앱의 "기록"에 `방해금지 켜짐 감지`가 언제 찍혔는지 보기
  → 실제 잠든 시각(아침에 삼성 헬스 기록)과 비교해서 "감지 지연 보정" 값 조정

## 주의
- 폰 수면 모드를 **정해진 시각에 켜지도록** 예약해 두었다면, 감지가 아니라 그 시각을 기준으로 알람이 맞춰짐.
  워치 감지로만 켜지게 해 두기
- 방해금지 중에 알람이 울리려면 방해금지 예외에 **알람**이 허용돼 있어야 함 (삼성 기본값은 허용)
- 이 앱은 보조용임. 꼭 일어나야 하는 시각에 기본 시계 앱 알람 하나는 따로 맞춰 두기
